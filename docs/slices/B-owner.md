# Slice B: owner app core

1. `src/components/Shell.tsx`: sticky blurred header with logo (14px lime square rotated 45deg + "LOOT" Unbounded 800 + "/<handle>" mono), desktop pill nav (Inventory "/", Activity "/activity", Stickers "/stickers", Settings "/settings"), `ThemeToggle`, primary "+ Add item" link to `/items/new`; below 720px a fixed bottom tab bar instead. Export `Shell({ children, title? })`. `src/components/ThemeToggle.tsx`: client component toggling `html[data-theme]` and localStorage `loot.theme`. Include a small logout form (server action) in the header when `OWNER_PASSWORD` is set.
2. `src/app/page.tsx`: inventory. Eyebrow "INVENTORY · n ITEMS TAGGED", h1 "The vault", category filter chips (All + CATEGORIES via `?cat=` searchParam), grid of item cards (22px radius): code mono + category pill, 4:3 photo or placeholder, badges (REPORTED LOST red, "Lent → name", "3D" when `model3d`), nickname + name, footer with a small inline QR (`qrSvg(code, { size: 42 })`) + "n scans" + link to the item. Last cell: dashed "Add new item" card. Empty state when there are no items.
3. `src/app/items/new/page.tsx` + server actions in `src/app/items/actions.ts`: fields nickname, name, category (chips), finderNote (textarea with a sensible default), up to 2 public stats (label/value pairs), private: serial, purchaseInfo, privateNotes. On submit `createItem` then redirect to `/items/[id]`.
4. `src/app/items/[id]/page.tsx`: detail + edit. Header (code, category pill, nickname Unbounded 800, name), photo card with upload form (server action: extension in `PHOTO_EXTENSIONS`, size <= `MAX_PHOTO_BYTES`, `saveUpload`, `removeUpload` old, `updateItem`), then `<ModelSection item={item} editable />`, QR card (156px `qrSvg`, `tagUrl`, "Open tag page" link to `/t/[code]`, "Download PNG" link to `/api/qr/[code]`, copy-link button as a tiny client component), "Report as lost" toggle (server action; adds a `lost`/`found` event) rendered red when on, lending card (lend to + due back; mark returned; adds `lend`/`return` events), edit form for all public fields, PRIVATE VAULT card (bg-colored, line3 border, pill "ONLY YOU · NEVER ON THE TAG") for serial/purchaseInfo/privateNotes, recent events for this item (`listEvents({ itemId })`), and a "Delete item" button with confirm (client) → `deleteItem` → redirect "/".
5. `src/app/login/page.tsx` + `src/app/login/actions.ts`: password form → `checkPassword` → `setSessionCookie` → redirect to `?next` (only allow same-origin relative paths starting with "/" and not "//") or "/". Logout action → `clearSessionCookie`.
6. `src/app/settings/page.tsx` + actions: edit owner handle, name, bio, contact, rewardLine, links (textarea, one "label | url" per line). Show `BASE_URL` and a warning if it contains localhost ("stickers will encode this URL").

All owner pages wrap in `<Shell>`. Use Server Actions for every mutation and `revalidatePath` after. Create a stub `src/components/ModelSection.tsx` only if it is missing.
