# Slice D: 3D model upload + viewer for the owner's own iPhone scans

Context: the owner scans their bike, phone or laptop with an iPhone app (Polycam, Scaniverse, RealityScan, KIRI, Apple Object Capture) and exports GLB, USDZ or OBJ (+MTL). They upload it per item. The finder tag page shows it when `model3dPublic`.

1. `src/app/api/items/[id]/model/route.ts`: `POST` multipart (fields: `model` file, optional `mtl` file, `public` "1"/"0"). Validate: extension in `MODEL_EXTENSIONS` (glb, gltf, usdz, obj), size <= `MAX_MODEL_BYTES`, mtl only together with obj. `saveUpload`, `removeUpload` the previous `model3d`/`model3dMtl`, `updateItem({ model3d, model3dMtl, model3dPublic })`. `DELETE`: remove files, null the fields. `PATCH` json `{ public: boolean }`. JSON responses. These are owner routes (the proxy protects them). Note: a `.gltf` that references external `.bin` or textures will not load; accept it but say in the UI that GLB (single file) is the format to export.
2. `src/components/ModelViewer.tsx`: `'use client'`. Props `{ src: string; ext: 'glb' | 'gltf' | 'obj' | 'usdz'; mtlSrc?: string | null; poster?: string | null; height?: number }`. Uses `three` (installed, ^0.187) directly: `WebGLRenderer` (antialias, alpha), `PerspectiveCamera`, `OrbitControls` from `three/examples/jsm/controls/OrbitControls.js`, `GLTFLoader` / `OBJLoader` (+ `MTLLoader` when `mtlSrc`) from `three/examples/jsm/loaders/...`, `HemisphereLight` + `DirectionalLight`, auto-frame the loaded object's bounding sphere, auto-rotate until the first interaction, `ResizeObserver`, dispose on unmount, loading and error states inside the box. For `usdz`: three.js cannot reliably render USDZ, so render a poster/placeholder tile with `<a rel="ar" href={src}>` "View in AR (iPhone)" which triggers AR Quick Look on iOS Safari, plus a download link. Lazy: show a placeholder with a "Load 3D model" button and only create the WebGL context after the tap (keeps the tag page light). Respect `prefers-reduced-motion` (no auto-rotate).
3. `src/components/ModelSection.tsx`: wrapper with props `{ item: Item; editable: boolean }` (it may render a client child). If `editable`: card "3D MODEL" with an upload form (client component using `fetch` to the route, upload progress with XMLHttpRequest, file inputs accepting `.glb,.gltf,.usdz,.obj` and `.mtl`, public toggle, delete button, help text: "Scan with Polycam, Scaniverse or RealityScan on iPhone and export GLB (best) or USDZ. OBJ needs its .mtl."), and the viewer when a model exists. If not editable: only the viewer (or the USDZ AR tile) under a label "3D MODEL · DRAG TO ROTATE". Use `uploadUrl(item.model3d)` for `src` and the file's extension for `ext`.

Do not edit lib files. Create a stub `src/components/Shell.tsx` only if it is missing.
